# AutoRepuestos · Backend

API REST para el sistema de gestión de inventario de AutoRepuestos.
Node.js + Express 5 + MongoDB Atlas (Mongoose).


## Endpoints

| Método | Ruta                  | Descripción        |
|--------|-----------------------|--------------------|
| GET    | /api/v1/productos     | Lista los productos |
| POST   | /api/v1/productos     | Crea un producto    |
